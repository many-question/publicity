# Publicity, public copies

Public copies of talks and other presentation materials. Each item is one folder, named by date and topic, holding only what its page needs. GitHub Pages serves each folder at its own path, with an offline package (zip) next to it: the page's control bar has a download button, and the unzipped folder plays from `index.html` in Chrome or Edge without a network.
